# 경영지원부 주간 업무 보고서 생성기

3명의 주간보고 엑셀(.xls/.xlsx)을 넣으면, **PDF 양식과 동일한 통합 주간 보고서 엑셀**을 자동으로 만들어 주는 Windows 프로그램입니다.

매주 월요일, 부서원들의 주간보고를 하나의 부서 보고서로 합치는 작업을 자동화합니다.

---

## 주요 기능

- **입력 자동 인식** : NOWSYSTEM 앱의 HTML형식 `.xls`, 진짜 엑셀 `.xlsx` 둘 다 지원
- **누락 0** : 입력 3개 파일의 모든 업무 내용을 빠짐없이 반영
- **PDF 양식 100% 재현** : 머리글 / 업무 체크리스트 / 구분별 본문 표 / 부서 공용 게시판
- **구분별 병합** : 담당자 표시 없이 경영관리·재무·조달/입찰·지원·R&D·현장 등 구분별로 통합
- **정렬** : `[루틴]` 위 → 일반 → `[신규]` 아래, 같은 구분 안에서 **유사 업무끼리 군집**
- **중복 확인 팝업**
  - 데일리 업무와 겹치는 본문 업무 → 뺄지 확인
  - 다른 구분에 비슷한 업무 → 합칠지 확인
  - 부서 공용 게시판이 파일마다 다르면 → 어느 내용 반영할지 확인
- **드래그&드롭** 으로 파일 추가
- **AI 요약본**(선택) : Claude API로 `구분별 핵심` + `완료/진행중/예정` 요약 별도 생성

---

## 실행 방법

### 1) 그냥 사용 (권장)
`주간보고서.exe` 더블클릭 → 파일 3개 선택/드래그 → 보고일 확인 → **보고서 만들기**

### 2) 파이썬으로 실행
```bash
pip install -r requirements.txt
python 주간보고서_생성.py
```

### 3) 실행 파일(.exe) 다시 빌드
```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name 주간보고서_생성기 ^
  --hidden-import openpyxl --hidden-import windnd 주간보고서_생성.py
```

## 설정 변경

`주간보고서_생성.py` 상단의 `[설정]` 구역에서 수정합니다.

| 항목 | 내용 |
|------|------|
| `부서명`, `보고자` | 머리글 정보 |
| `체크리스트`, `데일리_*` | 매주 고정되는 상단 표 |
| `구분_매핑`, `구분_순서` | 업무분류 → 구분 매핑/순서 |
| `이름목록` | 게시판에서 제거할 작성자 이름 |
| `재무_고정_게시판` | 재무 맨 위에 고정할 게시판 항목 |
| `조달입찰_고정_키워드` | 조달/입찰 맨 위 고정 표준 업무 |
| `CLUSTER_THRESHOLD` | 유사 업무 군집 강도 |
| `PAD_TOP`, `PAD_BOTTOM` | 셀 위/아래 여백 줄 수 |
| `AI_MODELS` | AI 요약에 쓸 Claude 모델 |

## AI 요약 사용 (선택)

1. 프로그램에서 **API 키 설정** → Claude API 키(`sk-ant-...`) 입력
   - 키는 프로그램 옆 `claude_api_key.txt`에 저장됩니다. **(git에 올라가지 않음)**
   - 키 발급 : <https://console.anthropic.com> → API Keys
   - 인터넷 연결 + API 사용 크레딧(결제) 필요
2. **🤖 AI 요약본도 함께 생성** 체크 후 보고서 만들기

> `claude_api_key.txt`는 비밀이라 `.gitignore`로 제외되어 있습니다. 절대 공개 저장소에 올리지 마세요.

## 필요 환경
- Windows
- Python 3 (실행 파일만 쓰면 불필요)
- 라이브러리: `openpyxl`, `windnd` (AI 요약은 표준 라이브러리 `urllib` 사용)
