   경영지원부 주간 업무 보고서 — 자동 생성 프로그램
════════════════════════════════════════════════════════════

■ 실행 방법
   "주간보고서.exe" 를 더블클릭하면 프로그램 창이 뜹니다.
   (파이썬 설치 없이 바로 실행됩니다.)

■ 사용 순서 (매주 월요일)
   ① "📂 파일 추가/선택" 버튼을 눌러, 3명이 NOWSYSTEM 앱에서
      내보낸 주간보고 엑셀(.xls) 3개를 선택합니다.
        · Ctrl 누른 채 하나씩, 또는 Shift로 여러 개 선택
        · 한 번에 안 골랐으면 버튼을 또 눌러 추가하면 됩니다.
        · 선택한 파일은 아래 목록에 표시됩니다.
   ② "보고일(월요일)" 칸을 확인합니다. (파일에서 자동 추정해
      채워줍니다. 틀리면 직접 수정, 형식: 2026-06-08)
   ③ "보고서 만들기 ▶" 버튼을 누릅니다.
   ④ 완료 메시지가 뜨고, 결과 엑셀이 자동으로 열립니다.
        결과 파일 :  경영지원부_주간보고_YYYYMMDD.xlsx
        저장 위치 :  첫 번째로 선택한 파일과 같은 폴더

■ 결과물 특징
   · 입력 3개 엑셀의 모든 업무 내용을 누락 없이 100% 반영
   · PDF 보고서와 동일한 양식
       - 머리글(◎ 경영지원부 주간 보고 ◎ / 보고일 / 보고자)
       - 업무 체크리스트 표 (고정)
       - 본문 표 : 구분 | 지난주 진행 업무 | 진행률 | 금주 예정 업무
       - 부서 공용 게시판 현황
   · 담당자 표시 없이 '구분(경영관리/재무업무/조달·입찰/지원사업/
     R&D사업/현장/기타업무 …)'별로 3명 업무를 병합

■ AI 요약본 (선택 기능)
   "🤖 AI 요약본도 함께 생성" 을 체크하면, 기본 보고서와 별도로
   AI가 요약한 파일을 하나 더 만듭니다.
        파일명 :  경영지원부_주간보고_AI요약_YYYYMMDD.xlsx
        내용   :  Ⅰ. 구분별 핵심 요약  /  Ⅱ. 완료·진행중·예정
   · 처음 한 번만 "API 키 설정" 버튼으로 Claude API 키를 입력하면,
     프로그램 옆에 저장(claude_api_key.txt)되어 다음부터 자동 사용됩니다.
   · 키 발급 : https://console.anthropic.com  → API Keys
   · 인터넷 연결이 필요하며, 호출당 소액의 사용료가 발생합니다.
   · AI 요약에 실패해도 기본 보고서는 정상적으로 생성됩니다.

■ 인쇄 / PDF 저장
   엑셀에서 [파일]-[인쇄] 또는 [다른 이름으로 저장]-PDF.
   (A4 세로, 가로 1페이지 맞춤으로 이미 설정되어 있습니다.)

■ 고정 내용(담당자·체크리스트·데일리 업무 등)을 바꾸려면
   "주간보고서_생성.py" 상단 [설정] 부분을 수정해야 하며,
   그 후 프로그램(.exe)을 다시 만들어야 반영됩니다.
   → 수정이 필요하면 요청해 주세요. (담당 작업)

■ 주의
   · 입력 파일은 반드시 NOWSYSTEM 앱의 "주간보고 내보내기"로
     저장한 .xls 여야 합니다. (엑셀에서 '웹페이지로 저장'한
     형식은 데이터가 별도 폴더로 분리되어 읽을 수 없습니다.
     이 경우 안내창이 뜹니다.)
   · 결과 엑셀이 열려 있으면 다시 만들 때 저장이 안 됩니다.
     먼저 닫고 실행하세요.
